# Submission checklist

- [ ] Live web app URL works at review time
- [ ] X API credentials configured on the server
- [ ] Natural-language query demonstrated
- [ ] Keyword query demonstrated
- [ ] Live/near-real-time X posts visible
- [ ] Author, content, timestamp and X link visible
- [ ] Screen recording or screenshots captured
- [ ] README/setup guide included
- [ ] Source repository provided
- [ ] Demo mode is NOT used as proof of live functionality
- [ ] No automated outreach is enabled
- [ ] API costs/limits have been reviewed before live testing
